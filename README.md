# worldcup_fate 🔮⚽

**2026 世界杯塔羅占卜系統** —— 以完整 78 張塔羅牌,**客觀**預言兩隊對戰的
勝負、讓分／受讓、大小分,以及上下半場的局勢變化。

> 占卜原則:只忠實於牌面,**不被**主觀強弱、賭盤賠率、過盤率所影響。

純 Python 實作,**無任何外部相依套件**(僅用標準函式庫),開箱即用。

---

## 快速開始

```bash
# 為一場對戰占卜(主隊在前、客隊在後)
python -m worldcup_fate 阿根廷 法國

# 指定賽事階段與日期
python -m worldcup_fate 西班牙 德國 --stage 八強 --date 2026-07-04

# 自動查表:依隊名帶入已查證的階段/日期/場館再開牌
python -m worldcup_fate 西班牙 奧地利 --auto

# 列出已收錄的賽程
python -m worldcup_fate --list-fixtures

# 以 JSON 輸出機讀結果
python -m worldcup_fate 巴西 英格蘭 --json

# 也可用根目錄的便捷腳本
python divine.py 葡萄牙 荷蘭 --stage 決賽
```

### 參數

| 參數 | 說明 | 預設 |
|------|------|------|
| `home` | 主隊名稱(先列出的隊伍) | 必填 |
| `away` | 客隊名稱(後列出的隊伍) | 必填 |
| `--stage` | 賽事階段,如:小組賽 / 32強淘汰賽 / 十六強 / 八強 / 準決賽 / 決賽 | `小組賽` |
| `--date` | 比賽日期 `YYYY-MM-DD`,影響命運種子 | 今日 |
| `--auto` | 依隊名自動查表帶入已查證的階段/日期/場館(查無則沿用手動值) | 關閉 |
| `--list-fixtures` | 列出已收錄的賽程後結束 | 關閉 |
| `--json` | 輸出 JSON 而非占卜報告 | 關閉 |

### 賽程自動查表(`--auto`)

直接爬 FIFA／新聞網站在出貨的 CLI 中並不可靠(多數站點以 403 阻擋爬蟲),
因此本專案改採更穩健的做法:在 `worldcup_fate/fixtures.py` 內建一份
**已查證的賽程資料集**,`--auto` 會依隊名(支援中英對照、順序不拘)自動帶入
正確的**階段、日期、場館與開賽時間**再開牌。

- 賽程資料整理自 2026 年 7 月的公開報導(每筆附 `source`),**最終請以 FIFA 官方為準**。
- 場館與開賽時間僅供顯示,**不影響命運種子**——帶入賽事資訊不會改變牌面。
- 要新增或更新賽程,直接編輯 `fixtures.py` 的 `FIXTURES` 清單即可。

## 運作原理

### 1. 命運種子(無法重抽)

同一場對戰、同一階段、同一日期,洗出的牌序與正逆位**完全固定**。
種子由 `SHA-256(主隊|客隊|階段|日期)` 決定,因此占卜者無法靠反覆重洗來
規避不想要的結果——命運一旦攤開即不可更改。

### 2. 七張牌世界杯戰局牌陣

| 位置 | 牌位 | 解讀面向 |
|------|------|----------|
| 1 | 主隊根基 | 主隊整體攻守能量 |
| 2 | 客隊根基 | 客隊整體攻守能量 |
| 3 | 上半場之相 | 開賽至中場的節奏與進球傾向 |
| 4 | 下半場之相 | 易邊後的局勢與體能消長 |
| 5 | 進球之潮 | 全場進球總體強度(大小分核心) |
| 6 | 關鍵變數 | 傷病、判罰、紅黃牌、爆冷的伏筆 |
| 7 | 最終定論 | 凌駕全局的總結與信心定調 |

### 3. 牌面數值屬性

每張牌都帶有一組可供足球解讀的**客觀數值**:

| 屬性 | 範圍 | 意義 |
|------|------|------|
| `attack` | 0–10 | 攻擊能量、製造機會的傾向 |
| `defense` | 0–10 | 防守穩固、抵抗壓力的傾向 |
| `momentum` | −5..+5 | 氣勢(正升、負降) |
| `volatility` | 0–10 | 變數、混亂、紅黃牌、爆冷傾向 |
| `goal` | 0–10 | 牌面指向「會有進球」的強度 |

- **大阿爾克那(22 張)**:逐張手工定義牌義與數值。
- **小阿爾克那(56 張)**:由「花色基礎屬性 + 階級調整」系統化推導,
  確保整副牌口徑一致。
- **逆位**:攻擊與進球被削弱、氣勢反轉、變數升高。

### 4. 預言推導(規則化、可重現)

- **勝負**:比較雙方綜合戰力,差距 > 2 判勝、之間判平。
- **讓分／受讓**:由預期分差換算半球盤口。
- **大小分**:由進球潮能量推估全場總進球,對標準盤 2.5 給出傾向。
- **上下半場**:比較上下半場牌的進球傾向與氣勢落差,判斷火力集中時段與氣勢轉折。
- **信心度**:變數越高、戰力越接近則信心越低。

## 專案結構

```

├── worldcup_fate/
│   ├── __init__.py       # 套件入口
│   ├── cards.py          # 78 張塔羅牌資料模型與牌組

│   ├── spread.py         # 七張牌世界杯戰局牌陣定義

│   ├── report.py         # 占卜報告渲染
│   ├── cli.py            # 命令列介面
│   └── __main__.py       # python -m worldcup_fate 入口
├── divine.py             # 根目錄便捷入口
├── tests/
│   └── test_divination.py
└── README.md
```

## 以程式呼叫

```python
from worldcup_fate import divine

reading = divine("阿根廷", "法國", stage="決賽", date="2026-07-19")

print(reading.winner)           # "home" / "away" / "draw"
print(reading.predicted_score)  # (1, 1)
print(reading.confidence)       # 57
print(reading.totals_text)      # 大小分文字預言
for key, dc in reading.cards.items():
    print(key, dc.card.name, dc.orientation)
```
